## 3학기 누적비와 서울 뒷구간

이 문서의 누적비 단위는 백분율 숫자(0~100)이다. 각 원표의 인접 기준점을 직선 보간한다. 원표의 1.16·1.66 등 표시 정밀도는 보존한다. 경기 보충값 1.059→1.169%, 1.111→1.72%, 1.389→4.92%에는 새로운 9등급 대응값을 만들지 않는다.

경기와 부산의 누적비를 G(x), B(x), 서울을 S(x)라 하자.

```
R(x) = (26511 G(x) + 15978 B(x)) / 42489
t(x) = (R(x) - R(3)) / (100 - R(3))               [3 < x ≤ 5]
S(x) = 51.06 + (100 - 51.06) t(x)                [3 < x ≤ 5]
F3(x) = (26511 G(x) + 15978 B(x) + 5000 S(x)) / 47489
```

서울 3.00까지는 원표를 사용한다. 그 뒤 남은 약 2,447명(5,000×48.94%)의 분포가 경기·부산의 해당 조건부 분포와 같다고 가정한다. 서울 인원을 분모에서 빼지 않는다. 3.00에서 값이 연속이고 5.00에서 100%가 된다. 남은 학생 수에 따른 보정이며 서울 뒷구간을 실제 관측했다고 주장하지 않는다.

## 5학기 누적비

서울 원고의 5학기 누적비를 S5(x)라 할 때:

```
F5(x) = F3(x) × S5(x) / S(x)                     [1 ≤ x ≤ 3]
F5(x) = F5(3) + (100 - F5(3)) t(x)                [3 < x ≤ 5]
```

3.00까지는 서울의 학기별 변화 비율을 전체에 적용한다. 이후에는 3.00까지 누적된 비율을 고정하고 남은 인원에 경기·부산 조건부 분포를 적용한다. 이는 검증 전의 추가 가정이다. 5학기 역시 서울 인원을 포함한 F3에서 출발하며, 3.00에서 이어지고 5.00에서 100%다. 지역별 5학기 실측이나 평균 산식이 통일된 자료가 확보되면 재보정해야 한다.

## 9등급 추정과 구간

각 원표의 과거 9등급/누적비 쌍으로 누적분포 H경기(q), H부산(q)를 직선 보간한다. 동일한 반올림 등급인 경기 1.24의 0.59%·0.61%는 누적 상단 0.61%로 합친다. 부산의 과거 대응값 1.09→0.2%, 1.15→0.3%, 1.19→0.4%는 과거 9등급 분포에만 사용하고 3학기 실측값으로 가산하지 않는다.

```
H(q) = (13896 H경기(q) + 15670 H부산(q)) / 29566
추정 9등급 = H의 역함수(F3(x) 또는 F5(x))
```

두 과거 분포의 등급 기준점 합집합에서 H를 계산하고 인접 누적비 사이를 역보간한다. 환산등급끼리 단순 평균하지 않는다. 경기 8.97 이후는 누적비 100%로 유지하며 합성 분포는 9.00에서 100%다.

최상위의 누락을 채우기 위해 각 과거 분포에 **가상의 경계 (9등급 평균 1.00, 누적비 0%)**를 추가해 첫 관측점과 연결한다. 실제 1.00 동점자 규모를 알 수 없어 사용하는 경계 가정이다. 이 가정은 기존 검토 엑셀에서 빈칸이던 최상위 5학기 추정값을 채우며, 경기 1.24 이상의 기존 합성값은 바꾸지 않는다.

화면의 추정 구간은 같은 누적비에서 경기·부산의 각 역산값과 합성분포의 인접 9등급 기준점을 모두 포함하는 최솟값~최댓값이다. 지역 원표 간 차이와 보간 근거 폭을 나타내며 **통계적 신뢰구간이나 개인 성적의 예측오차 범위가 아니다.** 검토 엑셀의 좁은 인접 기준점 구간에서 지역별 차이를 포함하도록 확장했다. 윤희태 53쪽의 별도 목표 범위표와 강제로 결합하지 않는다. 원표의 5등급 경계는 모델 결과 sourceBounds에 별도 유지한다.

## 구현과 검사

- 입력·표시는 소수점 둘째 자리. 중간 연산은 반올림하지 않는다. 시뮬레이션 최종 평균은 표시값으로 반올림한 뒤 동일 비교 모델에 넣어 비교표와 맞춘다. 목표 역산의 필요 성적은 목표를 넘지 않도록 둘째 자리에서 버림한다.
- 1.00~5.00 외부 값·공란은 오류 안내. 숨은 전국 순위나 대학 합격선 계산은 없다.
- 3학기·5학기 입력은 독립적으로 조절하며 같은 내신으로 맞춰 비교할 수 있다.
- 원표 기준점, 표본 가중치, 독립 기대값, 3.00 경계 연속성, 0.0001 간격 단조성·범위·구간 포함 여부, 전체 구간과 경계 입력, 기존 계산 기능을 검사한다.
- 계산 정확성 검사는 실제 예측 타당성을 입증하지 않는다. 검토 엑셀은 당시 모델을 보존하며, 웹은 위의 추가 보정 모델을 사용한다.

## 학기별 목표 성적 시뮬레이션

최종 시점은 3학년 1학기까지의 5학기다. 완료한 학기를 k, 학기별 단순 평균을 g_i, 반영 과목 수를 n_i라 두면 현재 성적 합은 A = Σ(i≤k) g_i n_i, 남은 반영량은 R = Σ(i>k) n_i, 전체 반영량은 N = Σ n_i다. 최종 목표 T에 필요한 남은 평균은 (T N − A) / R이고, 남은 평균을 u로 가정한 최종 평균은 (A + u R) / N이다.

기본값 n_i=1은 각 학기의 과목 수가 같다는 가정이다. 과목 수 보정을 켜면 완료한 학기의 실제 반영 과목 수와 남은 학기의 예상 과목 수를 사용한다. 학점 가중이나 대학별 학년 비율은 적용하지 않는다. 입력 평균이 소수 둘째 자리로 반올림되어 있으면 그만큼 재구성 오차가 있을 수 있다.

필요 평균이 1 미만이면 달성 불가, 5 이상이면 남은 성적에 관계없이 목표 이하로 분류한다. 1~5 구간의 필요 평균은 소수 둘째 자리에서 버림해 실행 가능한 상한을 제시한다. 남은 학기가 없으면 나누기를 수행하지 않고 확정된 최종 평균과 목표 달성 여부를 보여 준다. 아직 성적이 없는 경우에는 5학기 전체가 남은 것으로 처리한다. 목표 역산은 과거 분포 기반 예측이 아니라 입력 조건에 따른 산술 계산이다.
